Code Call-out 8.1: Quantile Effects with an Exogenous Treatment

In this code call-out we will explore some results documented in Firpo (2007), which require us to return once again to the LaLonde (1986) data we have discussed at length in Chapter 2. However, here rather than focussing on average treatment effects on the treated, we will focus on a range of quantile treatment effects (QTEs).

Estimating QTEs with Experimental Interventions

We will begin by exploring QTEs when treatment assignment is random, and does not require the incorporation of any controls. In these cases, at least for the estimates themselves, it is sufficient to simply directly calculate quantiles among the treated and control units. Let’s first load these data, and ensure that we know which our outcome and treatment variables are:

Now, with these data, let’s calculate some QTE. In particular, let’s calculate the quantity \(\tau_{QTE(0.8)}\), that is the effect at quantile 80. We can do this just by calculating the quantiles in each group:

* Compute the 80th percentile for the treated group
centile re78 if train == 1, centile(80)
scalar q80_treated = r(c_1)

* Compute the 80th percentile for the control group
centile re78 if train == 0, centile(80)
scalar q80_control = r(c_1)

* Compute the Quantile Treatment Effect at the 80th percentile
display "QTE(0.8) = " q80_treated - q80_control

Of course, we are not limited to doing this at the 80th quantile. We can inspect effects across the entire distribution by plotting cdfs for each group, and subtracting the control cdf from the treated cdf:

dis "SHOW TWO CDFs ON A SINGLE PLOT"
dis "THEN SHOW PLOT SUBTRACTING CONTROL FROM TREATMENT TO PLOT QTE ACROSS DISTRIBUTION"
* Groups
gen nonexp_control = (train == 0)  // Control no experimental
gen treated = (train == 1)         // Grupo tratado


local quantiles 25 50 75

foreach q in `quantiles' {
    centile re78 if treated == 1, centile(`q')
    scalar q`q'_treated = r(c_1)

    centile re78 if nonexp_control == 1, centile(`q')
    scalar q`q'_control = r(c_1)
}

* Mean calculation
summarize re78 if treated == 1
scalar mean_treated = r(mean)

summarize re78 if nonexp_control == 1
scalar mean_control = r(mean)


* Generate empirical CDFs for each group
gen re78_rank_treat = .
gen re78_rank_control = .

sort re78
replace re78_rank_treat = (_n - 1) / _N if train == 1
replace re78_rank_control = (_n - 1) / _N if train == 0

* Plot both CDFs on the same graph
twoway (line re78_rank_treat re78 if train == 1, lcolor(blue) lpattern(solid)) ///
       (line re78_rank_control re78 if train == 0, lcolor(red) lpattern(dash)), ///
       title("Empirical CDFs of re78 by Treatment Status") ///
       legend(label(1 "Treated") label(2 "Control"))

However, note that equivalently we can estimate these QTEs, along with their standard error, using quantile regression. Let’s confirm with ourselves that we can replicate the quantity \(\tau_{QTE(0.8)}\) by estimating a quantile regression.

dis "SHOW qreg HERE for quantile 0.8"
qreg re78 train, quantile(0.8)

As above, we can estimate this across a range of quantiles, giving a number of QTEs, and their confidence intervals:

dis "SHOW qreg HERE across distributions. Perhaps graphically?"

sqreg re78 train, quantile(0.25 0.5 0.75 0.9) reps(100)

* Create a new frame 
frame create qte_results
frame change qte_results
set obs 4  // Set number of observations to match quantiles

gen quantile = .
replace quantile = 0.25 in 1
replace quantile = 0.50 in 2
replace quantile = 0.75 in 3
replace quantile = 0.90 in 4

gen qte = .
gen qte_se = .

* Estimate QTEs across quantiles 
frame change default

local i = 1
foreach q in 0.25 0.50 0.75 0.90 {
    qui qreg re78 train, quantile(`q')
    matrix b = e(b)
    matrix v = e(V)

    * Store results in qte_results frame
    frame change qte_results
    replace qte = b[1,1] in `i'
    replace qte_se = sqrt(v[1,1]) in `i'
    frame change default

    local i = `i' + 1
}


frame change qte_results
gen qte_upper = qte + 2 * qte_se
gen qte_lower = qte - 2 * qte_se
list quantile qte qte_se if !missing(qte)


twoway (line qte quantile, lwidth(medium) lcolor(black)) ///
       (line qte_upper quantile, lpattern(dash) lcolor(black)) ///

Estimating QTEs and QTTs with non-Experimental Interventions

In cases where we instead believe that conditional unconfoundedness holds, there are two potential ways forward. To look at this, we will use the same LaLonde (1986) data, but now with the experimental treatment sample, and the non-experimental subsample as potential control units. We will control for the same factors we have discussed in code call-outs in Chapter 2. Let’s being by setting up these data:

dis "Open up Deheija Wahba data and subset to experimental and control sample"
clear all
set more off

* Load the data

Conditional QTEs

A first, simpler, case exists if we are happy to report conditional QTEs. Let’s begin by exploring conditional QTEs which can be estimated by quantile regression with covariates:

* Estimate CQTEs at selected quantiles (10th, 25th, 50th, 75th, 90th)
sqreg re78 treat age educ black hisp marr re74 re75, quantile(0.25 0.5 0.75 0.9) reps(100)

* Create a new frame 
frame create qte_results
frame change qte_results
set obs 4  // Set number of observations to match quantiles

gen quantile = .
replace quantile = 0.25 in 1
replace quantile = 0.50 in 2
replace quantile = 0.75 in 3
replace quantile = 0.90 in 4

gen qte_se = .

Unconditional QTEs

Finally, let’s see how we can fully calculate unconditional QTEs and QTTs. Below, we implement Firpo (2007)’s methods and estimate both QTEs and QTTs. We do this using the ivqte package, which implements these weighting-based estimators, along with their standard errors:

dis "SHOW QTEs and QTTs using ivqte with controls for unconditional exogenous effects"
net install ivqte, from("https://raw.githubusercontent.com/bmelly/Stata/main/")

ssc install moremata

* Load the data
use "Datasets/Dehejia_Wahba.dta", clear
* Variables are 
    *  TREAT 1 if treated (NSW treated) and 0 if not (PSID-1 control)
    *  AGE   in years
    *  EDUC  in years   
    *  BLACK 1 if black
    *  HISP  1 if Hispanic
    *  MARR  1 if married
    *  RE74  Real annual earnings in 1974  (pre-treatment)
    *  RE75  Real annual earnings in 1974  (pre-treatment)
    *  RE78  Real annual earnings in 1974  (post-treatment)
    *  U74   1 if unemployed in 1974
    *  U75   1 if unemployed in 1974

encode data_id, gen(id)
generate nsw=1 if id==2
replace nsw=. if id!=2
generate cps=1 if id==1
replace cps=1 if treat==1
label variable cps "CPS sample"

keep if cps==1|treat==1
tab cps treat
tab nsw treat
tab treat

* Conditional
ivqte re78 (treat), quantiles(0.25 0.5 0.75 0.9) continuous(age educ black hisp marr re74 re75)

* Unconditional
ivqte re78 (treat), quantiles(0.25 0.5 0.75 0.9) dummy(black hisp marr) continuous(age educ re74 re75)

* QTTs
ivqte re78 (treat), quantiles(0.25 0.5 0.75 0.9) dummy(black hisp marr) continuous(age educ re74 re75) variance
