Introduction to Pandas 🐼

What is Pandas?

Pandas is Python’s primary library for data manipulation and analysis

  • Built on top of NumPy
  • Provides two main data structures: Series and DataFrame
  • Designed to make working with “relational” or “labeled” data both easy and intuitive
  • Essential for any data science workflow in Python

Reshaping Data: Wide vs Long

Understanding Wide vs Long Format

Wide format: Each row is an observational unit, variables spread across columns

country    | gdp_2020 | gdp_2021 | gdp_2022
UK         | 2800     | 2950     | 3070
France     | 2600     | 2700     | 2780

Long format: Each row is an observation, with a column indicating the variable

country | year | gdp
UK      | 2020 | 2800
UK      | 2021 | 2950
UK      | 2022 | 3070
France  | 2020 | 2600

Different shapes for different tasks!

Merging and Joining Data

Types of Merges

Four main types of merges (similar to SQL joins):

  • Inner join: Only matching rows from both DataFrames
  • Left join: All rows from left DataFrame, matching from right
  • Right join: All rows from right DataFrame, matching from left
  • Outer join: All rows from both DataFrames

Understanding these is crucial for combining datasets correctly!

Merge Validation Options

The validate parameter helps catch data quality issues:

  • '1:1': One-to-one (each key appears once in each DataFrame)
  • '1:m': One-to-many (left keys unique, right keys can repeat)
  • 'm:1': Many-to-one (left keys can repeat, right keys unique)
  • 'm:m': Many-to-many (keys can repeat in both)

Best practice: Always use validate when you know the expected relationship!

Common Merge Issues

Problem 1: Unexpected duplicates

# Use validate parameter

Problem 2: Key formatting differences

# Standardize before merging
df1['id'] = df1['id'].str.strip().str.upper()
df2['id'] = df2['id'].str.strip().str.upper()

Problem 3: Different data types

# Convert to same type

df2['year'] = df2['year'].astype(int)

Pre-Merge Checklist

  1. Inspect your data

df1.head()

  1. Check key columns
# Are there duplicates?

# Are there missing values?
print(df1['key'].isna().sum())

Pre-Merge Checklist (cont.)

  1. Standardize keys
# Strip whitespace
df1['key'] = df1['key'].str.strip()

# Consistent case
df1['key'] = df1['key'].str.upper()

# Check data types match
print(df1['key'].dtype)

  1. Use validate and indicator

                  how='left',
                  validate='1:1',
                  indicator=True)

# Investigate non-matches

Summary and Resources

Key Takeaways

  1. DataFrames are the core data structure - get comfortable with them
  2. Indexing (.loc, .iloc, boolean) is essential for data selection
  3. Reshaping (wide ↔︎ long) depends on your analysis needs
  4. Merging requires careful attention to:
    • Key columns (names, types, values)
    • Merge type (inner, left, right, outer)
    • Validation of relationships
    • Post-merge checking

xkcd.com/2054

Essential Methods to Remember

Selection: .loc[], .iloc[], .query()
Cleaning: .dropna(), .fillna(), .astype()
Reshaping: .melt(), .pivot(), .pivot_table()
Merging: pd.merge() with validate= and indicator=
Grouping: .groupby() with .agg() or .transform()
Strings: .str.strip(), .str.upper(), .str.replace()

Common Pitfalls to Avoid

❌ Not checking for duplicates in merge keys
❌ Forgetting to standardize string keys (spaces, case)
❌ Mixing data types in merge keys
❌ Not using validate= parameter
❌ Not checking merge results with indicator=True
❌ Assuming inner join when you need left join
❌ Not resetting index after operations
❌ Modifying data without creating a copy first
