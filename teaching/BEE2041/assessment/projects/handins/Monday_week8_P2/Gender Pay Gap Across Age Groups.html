Selects only the rows and columns that contains age group and gender pay gap values (median)

# select the age group labels from the table
# rows 5 to 11 contain age groups
# column 0 contains the age group text
age = df.iloc[5:12, 0]

# select the gender pay gap values
# column 2 contains the median gender pay gap
pay_gap = df.iloc[5:12, 2]

# create a smaller DataFrame with selected data
clean_df = pd.DataFrame({
    "Age Group" : age,
    "Gender Pay Gap (%)" : pay_gap
})

print(clean_df)

Chart creation

import matplotlib.pyplot as plt

# create bar chart
plt.bar(clean_df["Age Group"], clean_df["Gender Pay Gap (%)"])

# axis labels
plt.xlabel("Age Group")
plt.ylabel("Gender Pay Gap (%)")

# title
plt.title("Gender Pay Gap Across Age Groups (UK, 2025)")

plt.show()

This bar chart illustrates the gender pay gap across ages groups in the United Kingdom in 2025. The results show that the pay gap is negligible among younger workers, with values close to zero for ages 16-21. The age gap increases steadily from age 30 and above, rising from 8.8% in the 30-39 group and a peak at 50-59 age group of 19.7%. The gap remains high beyond that age group as well. This pattern indicates that gender pay gap disparities widen with age, reflecting longer term career effects such as childcare related career interruptions and differences in career progression. The chart supports a conclusion that the gender paygap is substantialy larger in older age groups than younger ones.
