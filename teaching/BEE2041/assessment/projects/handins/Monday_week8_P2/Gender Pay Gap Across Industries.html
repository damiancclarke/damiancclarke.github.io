Loads raw dataset, reads only the All datasheet.

import pandas as pd
file = "PROV - SIC07 Industry SIC2007 Table 4.12  Gender pay gap 2025.xlsx"
df = pd.read_excel(file, sheet_name="All")

Pull necessary columns (industry name, code (A-U give overarching Industries) and median pay gap)

industry = df.iloc[:,0]
code = df.iloc[:,1]
median = df.iloc[:,2]

Create smaller DataFrame with those three columns.

clean_industry = pd.DataFrame ({
  "Industry": industry,
  "Code": code,
  "Gender Pay Gap (%)": median
})

Filter the so only the major industries (in bold and have a corresponding letter to it) are included

# take section letters from the code column (column 1)

Bar chat creation

import matplotlib.pyplot as plt

plt.bar(clean_industry["Industry"], clean_industry["Gender Pay Gap (%)"])
plt.xlabel("Industry")
plt.ylabel("Gender Pay Gap (%)")
plt.title("Gender Pay Gap by Industry (UK, 2025)")
plt.xticks(rotation=90)
plt.show()

The bar chart shows that the gender pay gap varies across industries in the UK in 2025. Some sectors have much larger gaps than others, suggesting that pay differences between men and women are linked to the type of work done in each industry. In particular, more physically demanding and traditionally male dominated industries, such as construction and manufacturing, tend to have higher pay gaps. This likely reflects the concentration of men in higher paid technical or supervisory roles within these sectors. Overall, the chart suggests that industry composition and job roles play an important role in explaining differences in the gender pay gap.
